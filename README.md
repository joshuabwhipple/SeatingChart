# Seating Chart Editor

## Installing Seating Chart Editor
To download Seating Chart Editor, first go to this repository's [releases](https://github.com/joshuabwhipple/SeatingChart/releases.), then select the appropriate installer.
For Apple computers, you will most likely need to download the "Mac (Apple Silicon)", but depending on the age of your device, you may need "Mac (Intel)". You can find out if your device has an Apple Silicon chip by following the instructions [here](https://support.apple.com/en-us/116943.).

## Using Seating Chart Editor

### New Chart
If you are looking to create a new seating chart, you would select "New Chart", and then enter the name of the chart, the number of rows, the total number of seats, and the list of singers. Each singer gets its own line and is formatted "First Name, Last Name, Part", such as "John, Smith, Part 1".
By default, the chart supports the following types: Soprano, Soprano 1, Soprano 2, Alto, Alto 1, Alto 2, Tenor, Tenor 1, Tenor 2, Bass, Bass 1, Bass 2, Part 1, Part 2. If you want to add and/or remove any types, you can check the "Custom Member Types" box and change the text in the box that appears. Parts are formatted as "Part Name, Color", such as "Part 1, Light Cyan".

### Load Chart
If you have been given a "\*.chrt" file or want to view/edit a chart you already created, you would select "Load Chart" and navigate to the "\*.chrt" file.

### Editing the Chart
Once you have created or loaded a chart, you will be able to find all unseated singers along the bottom of the screen. You can place them on the chart by clicking and dragging them onto one of the seats on the chart, which will turn red when selected.
Along the top of the screen is a bar with numerous functions. Starting from the left, there are some basic functions like creating a new chart, saving the current chart, or opening a different chart from a "\*.chrt" file. Further to the right are several buttons that allow you to change different base attributes of the chart, such as the number of seats, the singers in the chart, and the parts they can belong to. Finally is an export button, where you can export a picture of the chart as a PNG, JPEG, or PDF.
